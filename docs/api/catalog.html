GET /choiceProducts/{choiceProductUtid}/catalog

Operation ID: getChoiceProductCatalog.

Authentication: basic token (basicAuth) or bearer token (bearerToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | choiceProductUtid | path | string | Yes | Utid - Unique Tango Card ID | | verbose | query | boolean | No | When true, will return the additional brand fields: status, disclaimer, description, shortDescription, terms, brandRequirements collection, and imageUrls collection. | | brandKey | query | string | No | Returns the brand and item details for a specific brand ID. | | brandName | query | string | No | Returns the brand and item details for a specific brand name. | | utid | query | string | No | Returns the brand and item details for a specific utid. The utid is the unique identifier for a specific reward. | | rewardName | query | string | No | Returns the brand and item details of the specified reward name. | | status | query | string | No | Returns all brands and item details with the specified status. Possible statuses are: "test", "active", "inactive", "deleted" | | rewardType | query | enum: all, gift card, promo, donation, reward link, payment ach, ... | No | Returns all brands and item details with the specified rewardType. | | currencyCode | query | string | No | Return all brands and item details associated with a specific currency. | | country | query | string | No | Returns all brands and item details from a specific country. | | fulfillmentType | query | array of enum: DIGITAL, PHYSICAL | No | Returns all brands and item details for a specific fulfillment type. | | itemAttribute | query | enum: EMAIL, PHONE, ADDRESS, EMBEDDED | No | Returns all brands and item details for a specific item attribute. | | categoryIds | query | array of string (uuid) | No | Returns all brands and item details for specific brand categories. |
