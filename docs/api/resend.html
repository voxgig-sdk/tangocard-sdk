POST /lineItems/{referenceLineItemId}/resends

Operation ID: resendLineItem.

Authentication: basic token (basicAuth) or bearer token (bearerToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | referenceLineItemId | path | string | Yes | Reference line item id is returned in the line item response payload. |

Request body

application/json

Property Type Required Description
newDeliveryMethod enum: NONE, EMAIL, PHONE, WHATSAPP No The delivery method used to re-deliver the reward. If missing, the redelivery will use the delivery method used on the original order
newEmail string No A new email address to re-deliver this order to. If missing, use the original order email if deliveryMethod=EMAIL
newEtid string No A new etid used to re-deliver an order. If missing, use the original order etid.
newMobileNumber string No A new phone number to re-deliver this order to. If missing, use the original order phoneNumber of deliveryMethod=PHONE
otherReason string No Required when lineItemResendReasonCode is "OTHER", enter the reason why the line item is being RESENT
reasonCode enum: NOT_RECEIVED, LOST_DELETED, DELIVERY_INFO, DELIVERY_METHOD, REMINDER, OTHER No Enter the reason why this line item is being RESENT (respectively)
