create

POST /orders

Operation ID: createOrder.

Authentication: basic token (basicAuth) or bearer token (bearerToken).

Request body

application/json

Property Type Required Description
accountIdentifier string Yes Specify the account this order will be deducted from
amount number Yes Specify the face value of the reward. Always required, including for fixed value items.
campaign string No Optional. Campaign that may be used to administratively categorize a specific order. Must be between 0 and 1024 characters in length.
customFields object No Optional. A map of custom field key-value pairs configured at the account level for your platform. Only fields that have been configured for the account are accepted, any fields passed that are not configured will be silently ignored. Fields marked as required in the configuration must be provided; omitting a required field will result in a validation error. Fields marked as optional may be omitted. If no custom fields have been configured for the account, this property can be omitted entirely.
customerIdentifier string Yes Specify the customer associated with the order. Must be the customer the accountIdentifier is associated with.
deliveryMethod enum: NONE, EMAIL, PHONE, ADDRESS, EMBEDDED, EMBEDDED_COMPONENT, ... Yes Specify delivery method for the order
emailSubject string No Optional. Used with deliveryMethod is EMAIL. The ETID email subject will be used for the specified reward if not specified.
etid string No Optional. Used with deliveryMethod of EMAIL or PHONE. The unique identifier for the electronic template you would like to use. If not specified, the system will use the default etid.
expirationDate string No Optional for Promo Links, the exact calendar date the Promo Link will expire.
externalRefID string No Optional. Idempotent field that can be used for client-side order cross reference and prevent accidental order duplication. Will be returned in order response, order details, and order history.
message string No Optional gift message
notes string No Optional order notes. Must be between 0 and 1024 characters in length.
ptid string No Only required for Printed Reward Links, the unique identifier for the Printed Reward Link Template provided in the Tango Portal on the Printed Template page.
purchaseOrderNumber string No The Purchase Order Number associated with this order.
recipient object No Required if deliveryMethod is EMAIL, PHONE, or ADDRESS. May be required for some UTIDs. Use to set and store the recipient’s contact information. When deliveryMethod is NONE or EMBEDDED, setting these parameters will allow the platform to store this information for reporting, auditing, and reconciliation.
recipient.address object No Required if deliveryMethod is ADDRESS. May be required for some UTIDs. This field is optional for digital orders, NOTE: Some digital cash options may require including an address.
recipient.address.city string No Required if deliveryMethod is ADDRESS, not applicable for digital rewards. Allows 30 characters, not blank, Digits 0-9, alpha (a-z, A-Z), space, period, hyphen, ampersand, and apostrophe.
recipient.address.companyName string No Optional, Typically used when shipping to a corporate address.
recipient.address.country string No Required if deliveryMethod is ADDRESS, not applicable for digital rewards.
recipient.address.postalCode string No Required if deliveryMethod is ADDRESS, not applicable for digital rewards. Allows 5 characters, not blank, Digits 0-9 and alpha (a-z, A-Z). For US addresses this must include the five digit US ZIP Code only.
recipient.address.stateOrProvince string No Required if deliveryMethod is ADDRESS, not applicable for digital rewards. Address region must be a valid 2-character uppercase abbreviation for a U.S. state, territory, or military base; a Canadian province; or contain an international region less than 36 characters.
recipient.address.streetLine1 string No Required if deliveryMethod is ADDRESS, not applicable for digital rewards. Allows 35 characters max, not blank, Digits 0-9, alpha (a-z, A-Z), space, period, comma, hyphen, forward slash (/), ampersand, percent, pound (#), at (@), and apostrophe.
recipient.address.streetLine2 string No Optional if deliveryMethod is ADDRESS, not applicable for digital rewards. Allows 35 characters max, not blank, Digits 0-9, alpha (a-z, A-Z), space, period, comma, hyphen, forward slash (/), ampersand, percent, pound (#), at (@), and apostrophe.
recipient.email string No Required if deliveryMethod is EMAIL. May be required for some UTIDs. It is useful to include when deliveryMethod is PHONE to easily switch between email and phone delivery
recipient.firstName string No Required if deliveryMethod is EMAIL, PHONE, or ADDRESS. May be required for some UTIDs. Digital rewards: allows 100 characters, cannot use < or > or / in the name. Physical rewards: allows 25 characters max, Digits 0-9, alpha (a-z, A-Z), space period, comma, ampersand, and hyphen.
recipient.lastName string No Required if deliveryMethod is ADDRESS, otherwise optional. May be required for some UTIDs. Digital rewards: allows 100 characters, cannot use < or > or / in the name. Physical rewards: allows 25 characters max, Digits 0-9, alpha (a-z, A-Z), space period, comma, ampersand, and hyphen.
recipient.mobileNumber string No Required if deliveryMethod is PHONE. May be required for some UTIDs. Format: +CCCPPPPPPPPPPPP (where C is the country code, 1-3 digits, and P is the phone number, up to 12 digits). Follows ITU E.164, allowing (+) and up to 15 digits for the combined country code and phone number.
sendEmail boolean No Deprecated Oct 1, 2025. Should Tango Card send the email to the recipient?
sender object No Optional. Use to set the sender’s name and email address if different than the default platform setting.
sender.email string No always optional
sender.firstName string No always optional (100 character max)
sender.lastName string No always optional (100 character max)
utid string Yes The unique identifier for the reward you are sending as provided in the Get Catalog call
