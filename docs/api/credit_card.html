create

POST /creditCards

Operation ID: createCreditCard.

Authentication: basic token (basicAuth) or bearer token (bearerToken).

Request body

application/json

Property Type Required Description
accountIdentifier string Yes specify the account this credit card is associated with
billingAddress object Yes required Enter the billing address information for the credit card that is being registered
billingAddress.addressLine1 string Yes specify the billing address line 1
billingAddress.addressLine2 string No Optional. Specify the billing address line 2
billingAddress.city string Yes specify the billing address city
billingAddress.country string Yes specify the billing address 2-letter country code
billingAddress.emailAddress string Yes specify the billing address email
billingAddress.firstName string Yes specify the billing address first name
billingAddress.lastName string Yes specify the billing address last name
billingAddress.postalCode string Yes specify the billing address postal code
billingAddress.state string Yes specify the billing address state
contactInformation array of object No Optional. Enter the contact information of the any person(s) who will be notified if there are issues.
contactInformation[].emailAddress string No Optional. Used for email receipts. Specify the contact email address.
contactInformation[].fullName string No Optional. Used for email receipts. Specify the contact full name.
creditCard object Yes required Enter the credit card details that is being registered
creditCard.expiration string Yes specify the card expiration date in YYYY-MM format
creditCard.number string Yes specify the account this order will be deducted from
creditCard.verificationNumber string Yes specify the 3 or 4-digit card security code on back of card (CVV2, CVC2, or CID)
customerIdentifier string Yes specify the customer associated with the credit card. Must be the customer the accountIdentifier is associated with.
ipAddress string Yes specify the IP address of the person adding the credit card
label string Yes specify a label for the credit card
